# 🟢 HAZE EXECUTOR - Roblox Script Executor

Um executor de scripts Roblox poderoso com interface moderna inspirada no Arceus X Neo, com tema verde escuro e borda verde brilhante.

## 🎨 Características

- **Interface Verde Futurista** - Borda totalmente verde com interior verde escuro
- **Editor de Scripts Avançado** - Edição em tempo real com estatísticas
- **Biblioteca de Scripts** - Salve e gerencie seus scripts Roblox
- **Pesquisa de Scripts** - Encontre scripts facilmente pela busca
- **Console de Saída** - Veja logs e erros em tempo real
- **Auto-save** - Salve automaticamente seus scripts
- **Debug Mode** - Modo de depuração para análise detalhada
- **Injection Mode** - Modo de injeção para Roblox

## 📁 Estrutura do Projeto

```
haze-executor/
├── index.html      # Interface HTML principal
├── styles.css      # Estilos com tema verde
├── scripts.js      # Lógica JavaScript
└── README.md       # Documentação
```

## 🚀 Como Usar

1. Abra o arquivo `index.html` em seu navegador
2. Cole seu script Roblox no editor
3. Clique em "Executar Script" ou pressione o botão de play
4. Veja os logs no console abaixo

## 🎮 Scripts Pré-carregados

- **Hello World** - Script simples de teste
- **Sistema Info** - Informações do sistema
- **Teste Loop** - Loop de teste

## 🔧 Funcionalidades

### Editor
- Contagem de linhas
- Contagem de caracteres
- Tamanho do arquivo em KB
- Síntaxe Lua para Roblox

### Gerenciamento de Scripts
- ➕ Criar novo script
- 💾 Salvar script
- 🗑️ Limpar editor
- 🔍 Pesquisar scripts

### Execução
- ▶️ Executar script
- ⏹️ Parar execução
- 🐛 Debug mode
- 📝 Console detalhado

## 💾 Armazenamento

Os scripts são salvos automaticamente no localStorage do navegador.
